# Form đăng nhập Bootstrap — hoạt động 446

Mở `index.html` bằng trình duyệt. Form căn giữa trang, giới hạn 330px; email và password có label hỗ trợ trình đọc màn hình, autocomplete và required. Trình duyệt kiểm tra email trước submit. Submit hợp lệ chỉ hiển thị thông báo demo rồi xóa password; không gửi hoặc lưu thông tin đăng nhập. Remember me là thành phần giao diện minh họa.

Bootstrap 5.3.8 (MIT) lấy qua CDN có SRI theo https://getbootstrap.com/docs/5.3/ . Biểu tượng B SVG tự tạo cho bài thực hành, không phải bản logo Bootstrap chính thức. Layout dựa trên yêu cầu mẫu CodeGym; mã triển khai với trợ giúp Codex.
